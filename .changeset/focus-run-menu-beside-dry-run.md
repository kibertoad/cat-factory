The focus view shows the Run pipeline menu for a task beside the dry-run badge or switch, where before the dry-run control replaced it. An initiative no longer gets the menu: it keeps only Run planning, like the inspector. The menu locks and names the reason the same way the inspector does (no run permission, or unmerged dependencies), and its trigger shows the dry-run mode. The assistant no longer opens an added service frame in the focus view; it selects it on the board.
