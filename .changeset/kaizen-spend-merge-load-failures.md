Show a failed load or action as an error toast instead of an unhandled rejection: the Kaizen screen and the run window's Kaizen section, Resume anyway on the spend banner, the merge track record beside the class rules, the repository search, and a refused judge choice. A failed Kaizen overview or merge track record now says it could not be loaded instead of showing empty history, a Kaizen 503 that carries an outage reason is reported rather than read as "not configured", and repeated search or Kaizen failures replace one toast instead of stacking new ones.
