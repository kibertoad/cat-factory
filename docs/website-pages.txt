# Every page catfactory.ai serves, one URL path per line.
#
# `scripts/check-doc-links.mjs` refuses any https://www.catfactory.ai/... link in this repo's
# markdown whose path is not listed here. The point is ORDERING: the website page lands first, then
# its path is added here, and only then may a doc link it. The documentation revamp got that order
# backwards once and shipped fourteen links to pages that did not exist, across the root README, the
# four shipped SDK READMEs and six backend docs, several of them replacing material deleted in the
# same commit. Every one of them read as correct in review.
#
# This list is a RECORD, not a probe: nothing here contacts the site, so it can only be as honest as
# the person editing it. That is deliberate. A network check in CI is flaky and fails on the
# website's outages rather than on our mistakes, whereas adding a line here is a diff a reviewer sees
# and can refuse. Verify the page loads before adding its path.
#
# Sorted, and `docs/initiatives/documentation-revamp.md` records which topics are still unowned.
