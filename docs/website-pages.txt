# `scripts/check-doc-links.mjs` refuses any https://www.catfactory.ai/... link in this repo's
# markdown OR in its source, whose path is not listed here. The rule it enforces is ORDERING: the
# website page lands first, its path is added here, and only then may a doc or a remedy link it.
#
# Why a recorded list rather than a probe: nothing here contacts the site. A network check in CI is
# flaky and fails on the website's outages rather than on our mistakes, and it also cannot fail a PR
# that is merged BEFORE the page ships. Adding a line here is a diff a reviewer sees and can refuse.
# Verify the page loads before adding its path.
#

# which reader owns which. Sorted. Last verified against the live site: 2026-08-08.
